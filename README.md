## 💻 How to Run Locally

### Option 1: Direct Browser Launch (No Installation Required)
Simply double-click `index.html` or right-click `index.html` and select **Open with Chrome / Edge / Firefox**.

### Option 2: Using Any Local Server
Run with any lightweight static server:
```bash
# Using npx serve
npx serve .

# Or using Python's built-in server
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## ☁️ How to Deploy to Vercel

### Method 1: Deploy with Git & Vercel Dashboard (Recommended)
1. Push this folder to your GitHub account (e.g. `github.com/SachinMehra73/portfolio`).
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **Add New Project** and select your GitHub repository.
4. Leave build settings as default (Framework Preset: **Other**).
5. Click **Deploy**. Your site will be live instantly with a free `.vercel.app` domain and HTTPS!

### Method 2: Deploy using Vercel CLI
```bash
npm install -g vercel
vercel
```
Follow the short terminal prompts and your website will be live immediately.
